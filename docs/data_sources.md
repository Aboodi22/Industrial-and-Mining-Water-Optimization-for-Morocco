# Data sources and provenance

## Current dataset
The initial Khouribga case data are **synthetic** and created for demonstrating the software architecture and optimization formulation. No operational statistic is asserted to be official or observed.

Each dataset-level metadata record includes:
- source_type
- source_name
- source_url
- date_accessed
- licence
- confidence
- notes

## Future data
Any future published or official data must be checked for source authority, access conditions, licence, units, temporal coverage, and spatial reference system before use.
