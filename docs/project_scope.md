# Project scope

## Purpose
Decision-support simulation for industrial/mining water allocation and cost minimization.

## Case study
A simulated phosphate-processing facility inspired by the Khouribga region in Morocco. It is not an official model of OCP or any real industrial facility.

## MVP boundary
- One site and a 12-month horizon.
- Four water source types and four user categories.
- Deterministic monthly linear optimization.
- Cost-minimization objective.
- Synthetic input data with provenance.
- CLI solver output as the first result.

## Excluded
Real-time control, groundwater discovery, operational guarantees, automatic regulatory certification, hydrological forecasting, and machine learning.
